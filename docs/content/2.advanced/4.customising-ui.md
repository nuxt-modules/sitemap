## Disabling the XSL stylesheet

Nuxt Sitemap includes a stylesheet by default. Chrome deprecated XSLT and announced its removal. [Chrome's XSLT deprecation notice](https://developer.chrome.com/docs/web-platform/deprecating-xslt)

Set `xsl: false` to serve plain XML.

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  sitemap: {
    xsl: false,
  }
})
```

## Changing the columns

You can change the columns that are displayed in the sitemap by modifying the `xslColumns` option.

These have no effect on SEO and are purely for developer experience.

Note: You must always have a `URL` column at the start.

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  sitemap: {
    xsl: true,
    xslColumns: [
      // URL column must always be set, no value needed
      { label: 'URL', width: '75%' },
      { label: 'Last Modified', select: 'sitemap:lastmod', width: '25%' },
    ],
  },
})
```

The `select` you provide is an XSL expression that will be evaluated against the sitemap entry.
It's recommended to prefix the value with `sitemap:` if in doubt.

### Example: Adding priority and changefreq

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  sitemap: {
    xsl: true,
    xslColumns: [
      { label: 'URL', width: '50%' },
      { label: 'Last Modified', select: 'sitemap:lastmod', width: '25%' },
      { label: 'Priority', select: 'sitemap:priority', width: '12.5%' },
      { label: 'Change Frequency', select: 'sitemap:changefreq', width: '12.5%' },
    ],
  },
})
```

### Example: Adding `hreflang`

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  sitemap: {
    xsl: true,
    xslColumns: [
      { label: 'URL', width: '50%' },
      { label: 'Last Modified', select: 'sitemap:lastmod', width: '25%' },
      { label: 'Hreflangs', select: 'count(xhtml:link)', width: '25%' },
    ],
  },
})
```

## Disabling tips

The built-in stylesheet displays tips in development.

You can disable these tips by setting the `xslTips` option to `false`.

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  sitemap: {
    xsl: true,
    xslTips: false,
  },
})
```
